# 顺手 · 生活小事接收器

一个移动端优先、可安装到手机桌面的轻量 PWA。它把突然想到的小事先接住，再帮你挑出今天的一小步。

## 本地运行

需要 Node.js 18 或更新版本，不需要安装依赖：

```bash
npm start
```

然后在浏览器打开 `http://localhost:4173`。同一 Wi-Fi 下也可以用手机打开电脑的局域网地址和端口 4173。通过 HTTPS 部署后，浏览器支持时可以添加到主屏幕并离线打开。

## 当前包含

- 一秒捕捉待办、想买的东西和随手念头
- 今天聚焦最多三件小事
- “小事收纳篮”分类和完成状态
- 一小时后、今晚、明早的轻提醒，以及一键延后一小时
- 两个及以上选项的随机决定助手
- 本地保存，不需要注册账号或联网同步
- 可安装的 PWA 外壳和离线缓存

提醒会在 App 打开时检查；浏览器允许通知时，前台也会显示系统通知。网页关闭期间的定时推送需要后端推送服务，本 MVP 不包含该服务。

## 部署

这是静态前端，可部署到任何提供 HTTPS 静态文件托管的平台。将整个文件夹推送到用户自己的 GitHub 仓库后，可按需开启 GitHub Pages。
